# PORTIFOLIO-IHM-
Portfólio Pessoal — Interface Homem-Máquina

Sobre o projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal utilizando HTML5 e CSS3, como atividade acadêmica da disciplina Interface Homem-Máquina, do curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas.

O site apresenta informações pessoais, formação acadêmica, habilidades, projetos desenvolvidos e uma área de contato.

Objetivo

Aplicar os conhecimentos de desenvolvimento web, utilizando HTML5 semântico e recursos avançados de CSS para construir uma interface organizada, acessível, visualmente agradável e responsiva.

Tecnologias utilizadas

HTML5: estruturação do conteúdo e utilização de elementos semânticos.

CSS3: estilização, cores, tipografia e organização visual.

Flexbox: alinhamento e distribuição dos elementos.

CSS Grid: organização dos cartões de habilidades.

Variáveis CSS: padronização das cores e configurações visuais.

Media Queries: adaptação do layout para diferentes tamanhos de tela.

Seções do site

Início: apresentação pessoal com foto, nome e formação acadêmica.

Sobre mim: informações pessoais e objetivos na área de tecnologia.

Habilidades: apresentação dos conhecimentos em Linguagem C, MySQL e Linux.

Projetos: apresentação de atividades acadêmicas, com destaque para um projeto de banco de dados.

Contato: formulário para envio de mensagens.

Projeto em destaque

Banco de Dados de Ocorrências Aeronáuticas

Projeto acadêmico desenvolvido com MySQL para organizar informações sobre ocorrências aeronáuticas.

O banco de dados possui cinco tabelas: aeronave, fator_contribuinte, ocorrencia, ocorrencia_tipo e recomendacao, conectadas por meio de chaves primárias e estrangeiras.
